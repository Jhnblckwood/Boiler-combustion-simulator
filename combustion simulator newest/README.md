# Combustion Simulator — newest

Single self-contained file: **`index.html`**. Send it to anyone; it needs
nothing else and works opened straight from a phone or a PC.

- On a phone or a narrow window it shows the ± stepper layout with the
  sticky live-readings strip.
- On a PC it shows the range-slider layout with the sticky header.
- The link at the bottom of the page switches between the two layouts
  without losing your tuning points.

Both layouts run the exact same engine (physics, tuning workflow,
validation, analyzer lag, flameout/relight, L5X export), so they can never
drift apart. Actuator jitter is off for all four inputs.

Boiler: Cleaver-Brooks CBEX-2D · Hawk ICS parallel positioning · 30 ppm NOx
Natural gas, 1.43 MMBTU/hr min to 14.29 MMBTU/hr max input.
